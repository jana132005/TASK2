لغة CSS ودورها في تنسيق صفحات الويب

إعداد الطالبة: جنى إبراهيم إبراهيم علي

الرقم الجامعي: 2502320

المقدمة

أول ما ظهر الإنترنت كانت صفحات الويب شكلها عادي، كان الكلام أسود على خلفية بيضاء من غير أي ألوان. وبعدها ظهرت لغة CSS، وبقت هي المسؤولة عن تنسيق شكل وألوان صفحات الويب، وبقت من أهم اللغات اللي بيتم استخدامها في صفحات الويب.

ما هي لغة CSS؟

لغة CSS هي لغة تنسيق وليست لغة برمجة، والوظيفة الأساسية لها هي التحكم في شكل صفحة الويب. وهي اختصار لـ Cascading Style Sheets.

زي ما لغة HTML مسؤولة عن هيكل الصفحة والمحتوى، زي العناوين والفقرات والصور، لغة CSS مسؤولة عن تجميل الصفحة، زي تغيير لون النص أو نوع الخط وحجم العنوان ولون الخلفية.

كيفية عمل لغة CSS

تعمل لغة CSS عن طريق قاعدة تتكون من 3 أجزاء: المحدد، والخاصية، والقيمة.

مثال:

p {
    color: blue;
}

حرف p معناه كل الفقرات في الصفحة، و color هي الخاصية، و blue هي القيمة. وكده نقدر نغير شكل الموقع كله.

مميزات لغة CSS

  • تساعد على تنسيق صفحات الويب بشكل جميل.
  • تسهل التحكم في الألوان والخطوط.
  • توفر الوقت والجهد في تصميم المواقع.
  • تسمح بتصميم صفحات متجاوبة مع الهواتف.
  • تساعد على تنظيم شكل الموقع.

عيوب لغة CSS

  • قد تظهر اختلافات في العرض بين المتصفحات.
  • تحتاج إلى معرفة جيدة بخصائص التنسيق.
  • قد يصبح الكود معقدًا في المواقع الكبيرة.
  • تحتاج إلى تحديث وصيانة مستمرة.

الخاتمة

تعتبر لغة CSS من أهم اللغات المستخدمة في تصميم مواقع الويب، حيث تساعد على تحسين شكل الصفحات وتنظيم الألوان والخطوط، كما تجعل المواقع أكثر جاذبية وسهولة في الاستخدام.
